# AGENTS.md (dy-browse)

What it does and every flag are in the [README](README.md). The design is "Browsing Douyin" in `chat-bot/docs/own-experience-research.md`.

- **Pacing:** every click, keystroke and scroll follows [room-feed/AGENTS.md](../room-feed/AGENTS.md): wait for the target, pause 500–1000 ms, act, all through `Pace` (`@dy-apps/douyin-chrome`). Steps are classes over a surface interface (`src/app/`); only the surfaces in `src/page/` touch Playwright. Don't write a pause of your own.
- **Layers:** `core/`, `app/` and `douyin/` know neither Node (`node:*`) nor Playwright; files, processes, Claude and the browser are in `adapters/` and `page/`; `main.ts` wires them (`pnpm lint` enforces it). All file I/O goes through `DataStore` (`app/ports.ts`).
- **Read-only, never during a stream:** it never likes, follows or comments. Her comment drafts (`data/comments/`) are files for a person to review; there is no code that posts, and none is to be added without the stage 2 rules in the design doc ("Commenting"). `BrowseRun` refuses while port 8757 or 8758 listens and holds `data/browse.lock`; `VideoReader` re-checks before every tier-1 job. Never run it, or open douyin.com from a test, while a stream is on.
- **Selectors and JSON field names are guesses** (`src/douyin/page-map.ts`, `src/douyin/aweme.ts`, `tests/fixtures/`) until the first real run: see the README.
- **Shared with room-feed:** `Pace`, `SerialQueue`, `LoginFile`, Chrome's launch settings, `parseRoomMeta` come from `@dy-apps/douyin-chrome` (`douyin-chrome/`); don't copy them back. `BrowseChrome`, `core/knowledge.ts`, `adapters/claude-cli.ts` and `douyin/page-map.ts` are dy-browse's own, adapted.
- **Outputs go where the bot reads them** (`--bot-data`, default `chat-bot/data/`): the streamer's `<房间号>/memory/posts.md`, `browse/watched/<date>.md`, `knowledge/pending/`; only `--review` (and `--undo-review`) writes the knowledge base itself. Only state (run state, lock, feed log, searches, visits, marks, media, screenshots) stays in `dy-browse/data/`. Every path comes from an option, so tests use temp dirs or `MemoryStore`.
- **No `jest.mock`:** pass fakes in (`tests/support/`), as AGENTS.md at the root says.
