# 诅咒

观众送礼触发的诅咒，每种一个文件。`index.ts` 是注册表：加入一个诅咒，它就会出现在抽取池、规则说明和面板里。

| 诅咒   | 文件           | 稀有度   | 队列 | 效果                                                              |
| ------ | -------------- | -------- | ---- | ----------------------------------------------------------------- |
| 垃圾行 | `garbage.ts`   | rare     | `a`  | 底部加 1 行垃圾，把方块挤出顶部则游戏结束                         |
| 加速   | `haste.ts`     | uncommon | `b`  | 下降间隔 ×0.8，持续 5 轮，同时生效时相乘                          |
| 迷雾   | `fog.ts`       | common   | `c`  | 隐藏预览，持续 1 轮                                               |
| 封存   | `seal.ts`      | common   | `d`  | 禁用暂存，持续 1 轮                                               |
| 禁转   | `no-rotate.ts` | rare     | `e`  | 方块无法旋转，持续 1 块                                           |
| 自转   | `spin.ts`      | rare     | `e`  | 方块每 500 ms 自动顺时针旋转，无法手动旋转、软降、硬降，持续 1 块 |

1 轮 = 一次结算（3 块）。持续型诅咒每次触发都是独立的一份，各有自己的时长，几份可以同时生效：加速相乘，迷雾、封存只要还有一份在就生效。数字都在 `../config.ts` 里。

每个诅咒属于一个队列。每轮结算，每个队列里待执行的诅咒按顺序只执行 1 个，其余继续等待；队列名只是标签，和诅咒本身无关；禁转和自转都管旋转，所以共用队列 `e`，一轮只结算其中一个，其余各占一个队列。想让几个诅咒互斥，就给它们同一个队列名。

每 1 钻抽三次：是否触发；触发后抽稀有度（common 60%、uncommon 30%、rare 10%，只在场上有的稀有度之间分配）；再在该稀有度的诅咒里等概率抽一个。

## 新增一个诅咒

1. 新建 `<name>.ts`，用 `defineCurse` 写出名称、规则说明、稀有度、结算队列，以及需要的钩子：结算时的 `apply`、生效期间的 `blocks`（禁用旋转、暂存、软降或硬降）、`hidesPreview`、`gravityMultiplier`（下降间隔倍率，每份各乘一次）、每帧的 `onTick`、新方块出生时的 `onSpawn`。需要在钩子之间保存状态就写 `initState`。
2. 在 `index.ts` 的注册表里加上它，键名和 `type` 一致。

诅咒只能通过 `CurseContext` 看到棋盘和当前方块、使用自己的随机流、尝试旋转或改变形状，不能接触引擎本身。
