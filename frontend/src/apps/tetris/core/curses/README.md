# 诅咒

观众送礼触发的诅咒，每种一个文件。`index.ts` 是注册表：加入一个诅咒，它就会出现在抽取池、规则说明和面板里。

| 诅咒   | 文件         | 效果                                      |
| ------ | ------------ | ----------------------------------------- |
| 垃圾行 | `garbage.ts` | 底部加 1 行垃圾，把方块挤出顶部则游戏结束 |
| 加速   | `haste.ts`   | 下降间隔永久 ×0.8，可叠加，最快 140 ms/格 |
| 迷雾   | `fog.ts`     | 隐藏预览，持续 3 块                       |
| 封存   | `seal.ts`    | 禁用暂存，持续 3 块                       |

持续型诅咒生效期间再次触发会重新计时。数字都在 `../config.ts` 的 `effects` 里。

## 新增一个诅咒

1. 新建 `<name>.ts`，用 `defineCurse` 写出名称、规则说明和需要的钩子：结算时的 `apply`、生效期间的 `blocks`（禁用旋转或暂存）、`hidesPreview`、每帧的 `onTick`、新方块出生时的 `onSpawn`。需要在钩子之间保存状态就写 `initState`。
2. 在 `index.ts` 的注册表里加上它，键名和 `type` 一致。

诅咒只能通过 `CurseContext` 看到棋盘和当前方块、使用自己的随机流、尝试旋转或改变形状，不能接触引擎本身。
